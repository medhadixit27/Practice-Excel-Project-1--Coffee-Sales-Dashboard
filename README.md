# Practice-Excel-Project-1--Coffee-Sales-Dashboard
An interactive Excel dashboard designed to analyze global coffee shop transactions over a multi-year period (2019 - 2022).This project transforms raw relational data into actionable commercial insights—helping stakeholders understand customer purchasing behaviors, track sales performance across regions, and identify top-performing product variants.

Key Insights Captured-
1. Geographical Revenue Distribution
2. Product Dynamics (Coffee & Roast Performance)
3. Product Dynamics (Coffee & Roast Performance)

Excel Technical Stack & Concepts Used-
1. Data Modeling & Relationships
2. Advanced Formulas- XLOOKUP, INDEX/MATCH
3. Data Transformation
4. Dynamic Pivot Tables
5. Interactive Dashboard UI
